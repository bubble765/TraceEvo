# RAG候选扩充、拒绝校准与因果图质量评测

日期：2026-10-13。使用现有Qwen3-0.6B模型和50篇PMC语料，不重新诊断，不修改历史封存数据。

## Claim Map

| 待检验判断 | 最少证据 |
| --- | --- |
| 候选限制导致相关片段未进入重排 | 同一8条测试查询比较5×4与8×8候选配置，使用统一标注参考池 |
| 图质量可以分成可确定的合法性和来源约束的合理性 | 40例封存图硬规则检查、合成违规单元测试、独立语义审计试跑 |

## Experiment Blocks

1. 候选扩充：文档5→8，每篇子块4→8，最终最多4条。检查Precision@4、统一候选池Recall@4和返回内容的实际Precision。新增返回片段继续盲标，原标签只在问题、片段原文一致时复用。候选池Recall不解释为全库Recall。
2. 拒绝阈值：另外6条校准查询，包含4条预期可答、2条预期无答案。只用这6条的前4候选及模型标签，在logit分界值上最大化F1；原8条测试问题和评分不用于阈值选择。报告无答案拒绝率、有答案覆盖率与返回量，固定K指标与按实际返回量计算的Precision分开。
3. 因果图合法性：检查节点类型、空标签、假设分数范围、层级、悬空边、自环、重复边、支持/反驳目标、父子层级、父假设缺失、多父关系和refines循环。当前GoS存在Signal→Hypothesis锚定边，不能误当成假设层级边。对40例全部快照和最终图分别计算通过率。
4. 因果图合理性：复用现有审计提示词与引用校验，检查证据来源、假设细化、支持/反驳含义、置信度变化和报告触发条件。输出PASS/FINDINGS/UNCERTAIN与可引用的根事件、节点及原文；不删除、不恢复。先跑1例，之后由医学专家标注真实和注入异常样本，计算检测Precision/Recall、定位准确率、误报率和不可判断比例。

## Run Order and Milestones

| 阶段 | 判断门槛 |
| --- | --- |
| 单元测试 | 阈值过滤、类型规则、反例检测、记录不变性通过 |
| 扩充候选与补标 | 14条查询完成，原语料和标签哈希不变 |
| 校准与测试 | 仅校准组选择阈值，测试组完整评分；失败时保留未启用拒绝的选项 |
| 图评测 | 40例封存记录有效，硬规则与模型审计指标分开 |

## Risks and Mitigations

校准查询仅6条且模型标注未人工复核，阈值只属于试验配置，默认线上仍不自动启用。配置可通过参数复现，不把logit当概率。

图结构通过不等于医学推理正确；硬规则不通过也可能暴露原实现与新评测约束的差异。语义评测缺少人工金标准时，只报告审计发现，暂不报告检测准确率。审计输出或引用校验失败计UNCERTAIN。

## Compute and Data Budget

本机MPS，14条检索、最多64候选/查询；复用旧标注，只补标新前4结果与校准组。语义审计1例。预计数分钟至十余分钟，不运行新的诊断批次。
