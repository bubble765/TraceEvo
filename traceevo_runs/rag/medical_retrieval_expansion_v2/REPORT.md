# 候选扩充与独立拒绝校准

2026-10-13。语料50篇、2033子块，Qwen3-0.6B embedding/reranker不变。只做检索评测，未重新诊断。

文档候选5→8，每篇子块4→8，最终最多4条。原8条测试查询固定。另外6条查询专门校准，4条预期可答、2条预期无答案，全部24个前4候选做盲标。阈值通过这些校准配对最大化F1得到，没有使用原测试查询的标签选择阈值。

统一测试参考池为旧标注池与新返回前4条的并集；旧标签只在问题和上下文原文一致时复用。总计383组标签，其中356组复用。1个校准批次引句校验失败，失败记录保留，补跑后完整覆盖。测试组相关配对数仍为47。

## 结果

| 指标 | 原5×4 | 扩充8×8 | 扩充加拒绝 |
| --- | ---: | ---: | ---: |
| 返回条数 | 32 | 32 | 22 |
| 相关条数 | 15 | 14 | 14 |
| 实际返回Precision | 46.9% | 43.8% | 63.6% |
| 固定分母Precision@4 | 46.9% | 43.8% | 43.8% |
| 候选池宏平均Recall@4 | 44.4% | 37.3% | 37.3% |
| 命中至少一条相关片段的查询 | 6/8 | 6/8 | 6/8 |
| 无答案查询全部拒绝 | 0/2 | 0/2 | 2/2 |

扩充单独使Precision@4下降3.125个百分点，相对下降6.7%。扩大候选数量不是自动改善，新增干扰候选会改变重排的前4顺序，因此默认配置保留5×4，8×8可选复现。

独立校准得到logit阈值0.7109375；校准组接受12条，其中8条相关，Precision66.7%、相关接受Recall100%、F1为0.8。测试组过滤掉10条无关片段，没有损失扩充配置原本返回的14条相关片段，实际返回Precision提高19.9个百分点，相对提高45.5%。固定K分母指标不会因返回数量下降而自动上升，两个Precision口径明确分开。

阈值只针对当前Qwen3固定版本、当前语料和8×8候选设置。6条校准和8条测试规模小，标签由模型产生；不能声称泛化已经验证。没有对全2033块逐查询标注，因此Recall仍为候选池口径。

## 可复现配置

医学RAG开启时设置文档候选8、每篇子块8、最大返回4、最小reranker分数0.7109375。当前提供CLI参数，不自动启用这个试验阈值。原索引与历史评测结果保持不变。
