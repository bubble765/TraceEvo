# 40例建库病例的经验检索测试

日期：2026-10-09。

本轮覆盖两批共40例已完成诊断的病例。38例具有合格的初始症状摘要，2例无法评估，原批次case-7和case-17的检查前文本过短或缺失。二者单独保留，不计为检索失败。

## 测试口径

使用现有9条合格成功协作经验，检索通道为initial_plan。失败防错经验属于恢复通道，未混入本次症状匹配测试。每例在检索、重排和标注前排除同一来源文章的经验及完全相同的症状文本，累计排除9组自身经验，实际自命中为0。

两批病例均曾参与经验积累，因此本轮属于排除自身经验的建库病例交叉检索测试。此前10例独立留出评测保持不变，两轮结果分开报告。

检索使用Qwen3-Embedding-0.6B与本地Qdrant；重排使用Qwen3-Reranker-0.6B。每例剩余8或9条经验全部参与候选排序，指标只检查前5条。拒绝阈值关闭，所以返回结果数量不能代表相关性。

deepseek-v4-flash以统一none推理设置，对所有333组有效“病例—经验”配对进行盲评，只看初始症状摘要及协作策略，隐藏诊断答案、排名和检索分数。38例全部完成标注，无标注失败。相关性等级为0（无关）、1（部分可借鉴）、2（高度匹配）。这些等级仍需临床专家复核。

## 结果

按等级至少为1的相关口径：

| 指标 | 纯向量排序 | 向量检索后重排 |
| --- | ---: | ---: |
| 前5条命中至少一条相关经验的病例数 | 30/38 | 29/38 |
| 前5条相关匹配次数 | 59 | 55 |
| 命中经验去重条数 | 9 | 9 |
| 首条相关的病例比例 | 24/38，63.2% | 24/38，63.2% |
| 前5条病例命中率 | 78.9% | 76.3% |
| Precision@5 | 31.1% | 28.9% |
| 宏平均Recall@5 | 94.4% | 88.3% |
| 微平均Recall@5 | 59/64，92.2% | 55/64，85.9% |
| MRR@5 | 0.883 | 0.872 |

重排后宏平均Recall@5降低6.1个百分点，相对降低约6.5%。前5条相关匹配减少4次，命中病例减少1例。本轮证据没有支持重排优于纯向量排序。线上排序规则保持不变。

38例中有30例在库中存在相关经验，累计64组相关配对；其余8例在库中没有相关经验。重排后的29例命中、1例漏掉全部相关经验，8例缺乏相关经验。按全部40例记录展示，29例命中、9例有效但未命中、2例无法评估。

按等级2的高度匹配口径，前5条共9例命中，9次匹配，涉及5条不同经验；9组高度相关配对全部找回。这个口径下宏平均与微平均Recall@5均为100%，但只覆盖9例。

## Recall怎样计算

先对某个病例与库中所有可用经验逐一标注相关性，得到该病例的全部相关经验集合。自身经验已从集合中排除。

单例Recall@5 = 前5条命中的相关经验条数 / 库中该病例全部相关经验条数。

实际例子：原批次case-2的初始症状包括儿童发育迟缓、小头畸形及肌张力异常。盲评认为库中3条经验部分相关，前5条找回2条，因此该病例Recall@5为2/3，即66.7%。相关性由模型判定，须人工复核。

宏平均：对库中存在相关经验的30例，先分别计算Recall，再取平均，得到88.3%。库中完全没有相关经验的8例无法定义单例Recall，另行统计；缺少合格输入的2例也不参与计算。

微平均：把所有病例的相关匹配次数相加后计算，55/64 = 85.9%。同一条经验可与多个病例相关，因此64和55统计的是病例—经验配对数。

病例命中率按病例数统计，本轮为29/38 = 76.3%；它回答有多少病例至少找到一条相关经验。Recall按相关经验的找回程度统计，能反映一个病例有多条相关经验时是否漏检。
