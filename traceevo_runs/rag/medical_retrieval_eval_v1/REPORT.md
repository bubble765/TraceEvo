# 医学知识库检索试测

日期：2026-10-13。

## 范围与方法

现有schema-v5医学库包含50篇PMC OA文献、2033个子块。本轮手工固定8条英文查询：成人踝部影像规则、下胫腓联合损伤、结核性脑膜炎检查、肌钙蛋白诊断心梗、ANA诊断特异性、尿路感染检查，以及预期缺少答案的睾丸扭转和苯丙酮尿症查询。查询未从正文自动生成或复制；主题按当前库覆盖情况选择，属于小规模试测。

正常链路保持文档标题/摘要向量召回5篇、每篇召回4个子块、全局重排、返回4条，上下文最多900 token、锚块预算480、相邻句预算200。比较同一组分层候选的子块向量排序与Qwen3重排结果，不修改生产检索逻辑。查询直接进入当前医学检索器，本次未额外启用query reformulation。

复制现有Qdrant索引到独立试测目录。原索引未修改；结束时校验原归一化语料文件哈希保持一致。embedding和reranker沿用固定版本的Qwen3-0.6B模型，本机MPS执行。

每条查询的标注池包含正常分层检索的全部候选、全库向量前20条和BM25词项前20条，按chunk_id去重，合计356组查询—片段配对。标注使用与检索排名隔离的deepseek-v4-flash，统一temperature=0、reasoning_effort=none。评估模型看到问题、来源标题及上下文回填后的片段，隐藏候选来源、排名与检索分数。

等级2表示片段直接回答问题的一项实质内容，等级1仅提供背景，等级0无关。主指标只计算等级2。每个等级2标注必须附带原文连续引句，程序核对该引句确实存在。全部356组完成标注，格式与引句校验失败为0。

## 指标含义

Precision@4 = 返回前4条中的相关条数 / 4。越高表示无关内容越少。本轮按全部8条查询计算，包含无答案查询。

单例候选池Recall@4 = 前4条找回的相关条数 / 标注池中该查询的全部相关条数。宏平均先分别计算，再对存在相关内容的6条查询取平均；无相关内容的2条另行统计。

微平均候选池Recall把所有查询—片段配对汇总：找回的相关配对总数 / 标注池中全部相关配对总数。

本轮尚未对全部2033块进行逐查询标注，因此这里的Recall只针对候选池，不能表述为整个知识库的完整召回率。池外可能还有相关内容，候选池Recall可能偏高。

## 实测结果

| 指标 | 纯向量排序 | 重排后 |
| --- | ---: | ---: |
| Precision@1 | 62.5%（5/8） | 62.5%（5/8） |
| Precision@4 | 43.8%（14/32） | 46.9%（15/32） |
| 候选池宏平均Recall@4 | 38.8% | 44.4% |
| 候选池微平均Recall@4 | 29.8%（14/47） | 31.9%（15/47） |
| 前4条至少命中一条相关片段的查询数 | 6/8 | 6/8 |

重排后Precision@4提高3.125个百分点，相对提高7.1%；候选池宏平均Recall@4提高约5.56个百分点。重排仅多找回1组相关配对，样本量不足以声称稳定改善。

| 查询 | 标注池直接相关条数 | 重排前4条相关数 | Precision@4 | 候选池Recall@4 |
| --- | ---: | ---: | ---: | ---: |

只看6条有相关内容的查询，Precision@4为15/24，即62.5%。这项结果与包含无答案查询的主指标46.9%分开报告。

## 发现与下一步

下胫腓联合损伤查询的前4条全部相关，但池中有21条相关片段，导致片段级Recall只有19.0%。这说明返回内容的准确性与找回全部相关片段是不同目标；文献重复讨论和上下文重叠也会影响该指标。当前尚未评估去重后的知识点覆盖。

两条无答案查询的池内相关内容均为0，系统仍各返回4条结果。检索器当前未启用拒绝阈值，应使用独立验证查询校准阈值，避免把靠前但无关的结果提供给专家。池内无答案也不等于已经证明全库不存在答案。

ANA查询的前4条仅1条直接相关，属于重点复核对象。下一步先人工检查模型标签和未召回片段，再定位文档路由、每篇子块粗排、重排各阶段的损失。

阶段检查发现：47组池内相关配对中，只有15组进入正常分层检索候选集，重排后的前4条已找回这15组。当前主要损失发生在候选生成阶段，尤其需要检查文档路由及每篇仅4个子块的限制；继续调整重排不能找回未进入候选集的片段。

本轮模型标注仍可能误判，引用存在仅验证出处，不能保证医学理解正确。8条主题查询不代表完整临床查询分布。报告没有衡量诊断正确率提升，也没有验证大规模HNSW性能；本地Qdrant进行精确检索。
