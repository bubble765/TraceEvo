## 4. 最成功的 3 个结果

1. **T1 的按位置回放设计，使「非侵入性」从论证变成证明。**
   由于 prompt 变化会导致回放 key 校验失败，B 与 C 的完全一致同时排除了「改了 prompt」和「改了控制流」两种可能。这比统计比较强得多，而且它会**主动失败**——开发中它确实失败了三次，每次都指向一个真实缺陷。

2. **T4 的「与 GoS 自己写出的图对比」抓到了自洽性检查发现不了的缺陷。**
   `diff_states` 用 `set(dict)` 求边差，因此**边类型从 support 翻成 refute 时 delta 显示「无变化」**。只做自洽重放永远发现不了；拿重建结果去比外部真值，case 8 立刻 7/10 失败。修复后 10/10。

3. **S1 让「证据无来源」从一次性观察变成可重复指标。**
   S0 的 27.7% 是一次性脚本产物（评审决定 D2 已判定不能作为论文数据）。S1 用事件绑定重新计算，并给出规则敏感性，使这个数字**可复核、可被质疑、可被改进**。同时逐条分析显示这 41.6% 并非同质——混有缺失陈述、近似改写、专家结论三类，这直接改变了 S2 的注入设计（见报告 §6.1）。

## 5. 最失败的 3 个结果

1. **A 组的真实性被续跑削弱。**
   理想情况是 A 组为一次完整的真实运行。实际因一次 51 分钟的挂起，A 组的前 221 次调用来自被中断的那次运行，其余为真实调用。A==B 因此部分是构造性的。主结论（B==C）不受影响，且单例全真实运行也验证了回放忠实性，但这是一个应当记录的方法学折扣。

2. **`status` 与 `model_version` 两个字段名存实亡。**
   上游根本不存在逐操作的成功/失败语义与模型版本信息。S1 只能填入恒定值。这意味着计划 §6.1 的 `B(τ)`（能力边界）与证据版本核验**无法在现有上游上完整实现**。这是 S1 未解决、也不能单靠 S1 解决的问题。

3. **41.6% 的绑定失败里混着测量误差。**
   逐条检查发现，相当一部分「无来源」节点其实是**同义改写**（如 `"Skin biopsy shows lymphocytes obscuring the dermal-epidermal junction"` 与库中 `"…demonstrates lymphocytes obscuring the dermal-epidermal junction"`），覆盖率 0.29–0.50，恰在主阈值 0.6 之下。用一个 token 覆盖率阈值同时承担「判断是否有来源」和「判断是否同义改写」是勉强的。敏感性表能暴露这一点，但没有解决它。

## 6. 尚未解决的问题

1. **「有来源」的判定标准未定。** 阈值 0.6 是工程取值。把它调低会让绑定率上升到 43.9%（覆盖率≥0.4），调高降到 26.3%。**S2 需要先决定这条边界，否则异常检测的 F1 会被边界选择主导。** 注意：缺失陈述（8 个）应当与「无来源断言」分开，前者是真实的推理产物。

2. **消费类事件的 `causal_node_refs` 只是近似。** PLAN/ANALYSIS 究竟读了哪些节点，上游无记录（prompt 里是整个图的序列化，理论上全部节点都影响了决策）。S1 只挂了焦点节点。要做到「每个 Hypothesis 由哪些证据推出」，需要 prompt 级消融——**这是否属于本论文范围，需要评审明确**。

3. **上游存在会整例中止的缺陷，但 S1 无权修复。**
   中心智能体规划出 `"Laboratory Physician"`（空格）而非 `"Laboratory_Physician"`（下划线）时，`act()` 抛 `ValueError: Not founded`，整例中止，无规范化、无重试。S1 禁止改变 GoS 行为，故未修复。**S2 需要决定：这是审计对象（记录并报告异常），还是需要在上游加一层健壮性处理。**

## 9. 需要外部评审回答的问题

1. **`status` 字段的空洞应当如何处理？**
   上游没有逐操作成功/失败语义；专家预算耗尽时静默返回降级文案。三个选项：(a) S2 先补一个最小可观测信号（会轻微改变上游行为，需记录为偏差）；(b) S2 只审计可得的子集，明确声明完整性审计不完整；(c) 接受现状，把「静默降级」本身作为 S2 要检测的异常类型之一。
   我倾向 (c)——它把限制变成一个研究对象，但这会让早期审计 F1 偏低。请评审指定。

2. **消费类事件的 `causal_node_refs` 近似是否可接受？**
   目前只能保证「节点由哪个事件**产生**」，不能保证「节点由哪些证据**推出**」。后者需要 prompt 级消融，成本高且可能超出第一篇论文范围。若评审认为这是必须的，S1 需要追加一轮工作。

3. **T1 的 A 组真实性折扣是否影响你对非侵入性结论的接受？**
   主证据是 B vs C（两者都是对同一记录的纯回放，仅 instrumentation 开/关不同）。若评审认为 A 组必须是完整真实运行，需要约 2 小时重跑；我判断没有必要，但愿意执行。
